# Changelog

## v0.1.0 — first public release
- Ten calculators: flow regime and dimensionless numbers; near-wall resolution (y⁺, first cell, inflation layers,
  RANS/WMLES/WRLES/DNS spacing); turbulence scales, LES/DNS resolution and RANS inlet values; finite-element element
  size and time step (heat conduction, structural dynamics); Lagrangian particles; FDS fire planner; premixed flame
  resolution and combustion regime; time step and stability; grid convergence index (Celik et al., 2008);
  simulation budget (cells, memory, run time, storage).
- Unit conversion on every input, warnings for inputs outside correlation validity, theory and references per calculator.
- PDF export (single calculator or full report), Markdown export, project files (.dsz).
- Verified against published values (see the manual, "Verification").
